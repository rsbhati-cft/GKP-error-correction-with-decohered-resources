# GKP-error-correction-with-decohered-resources
This project presents a study of teleportation based GKP error correction when the shared Bell pair goes through decoherence due to interaction with a bosonic environment. The python code in this repository is used to generate data for the figures in the article arXiv:2609.31462v1.
The code GKP_EC_decohered_resource.py uses QuTiP to model the GKP EC. 
Data for the plots can be generated using commented out scripts at the end of the program file.
